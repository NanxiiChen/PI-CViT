# 2D Navier Stokes Equations

We consider the 2D incompressible Navier-Stokes equations given by:
\[
\frac{\partial \mathbf{u}}{\partial t} + (\mathbf{u} \cdot \nabla) \mathbf{u} = -\nabla p + \nu \Delta \mathbf{u},
\]
subject to the incompressibility condition:
\[
\nabla \cdot \mathbf{u} = 0,
\]
where \(\mathbf{u} = (u, v)\) is the velocity field, \(p\) is the pressure, and \(\nu\) is the kinematic viscosity.
