## 1. 目的

对 FEM 真解、adam / soap 训练的 CViT，在同一套时空网格点上计算 PDE 残差 loss（FD 与 autodiff 两种估计器）与 L2 误差，并解释不同口径数字之间的关系。

**本轮相对上一版的关键改进**：时间导数改用精细步长 dt=0.001 的差分（此前用的降采样 dt=0.1），消除了 FEM 侧的时间差分截断误差。loss 评估仍在 31 个粗时刻（每 0.1）进行。

## 2. 问题设定与无量纲化

**PDE 残差**（与 `ice_melting/losses.py::residual_pde` 完全一致，物理单位）：

```
r = ∂φ/∂t − M ( Δφ − (φ³−φ)/ε² ) + λ·√(2F)/ε ,    F = (φ²−1)²/4
```

无量纲化（核实自 `configs/train_cvit.py` + `train.py` + `sample.py`）：模型用归一化坐标 x̂=x/Lc∈[−0.5,0.5]（Lc=100）、t̂=t/Tc∈[0,1]（Tc=3）；`residual_pde` 对归一化坐标导数做 ÷Tc、÷Lc² 换回物理单位；M=0.1、λ=5、ε=2.2871 为物理单位。

**求导方式**：
- FD（FEM 与模型同款算子）：时间导数用相邻精细帧中央差分（dt=0.001，两端二阶单侧）；空间拉普拉斯中央差分 + 边界单侧（dx=dy=100/63）。先在归一化坐标差分再 ÷Tc、÷Lc²。
- autodiff：训练同款 `Losses.residual_pde`，对网络精确求导，在评估网格点求值。

网格：64×64，界面宽度 √2ε≈3.2 仅约 2 个网格点（欠解析）。

## 4. 分析

### 4.1 FEM 的 FD 读数（2.1e-4）现在是干净的下限估计

时间截断误差已消（t=0 帧从粗数据的 4.06e-4 降到 2.53e-4 可证），剩下的 2.1e-4 几乎全部来自**空间方向**：界面只有约 2 个网格点宽，二阶差分在陡峭 tanh 前沿上的截断误差 + CG1 离散解自身的亚网格结构。这是该网格分辨率下 FD 估计器的物理地板，比模型的 autodiff 残差高 1~3 个数量级。

### 4.2 模型的 FD (dt=0.001) 读数无效：网络在时间方向有小尺度粗糙度

网络输出 φ̂(t̂) 在小尺度上的时间结构从未被训练约束（随机 Fourier 时间特征频率仅 O(1)，但 tanh-MLP+FiLM 解码器在该尺度上本质上是"噪声"）。对它做 dt=0.001 的差分，噪声被 1/(2dt)≈1500 倍放大（3.3 节的 1/h 标度直接证实），于是 adam/soap 的 FD 读数高达 7.2e-3 / 3.4e-2——**这是数值微分伪影，不是物理残差**。FEM 数据不受影响，因为求解器真实地以 dt=0.001 步进，数据在该尺度上是光滑的。

补充诊断（adam，t=1.5，h=0.001，|FD−AD| 的空间分布）：粗糙度**集中在界面带**（|φ_FEM|<0.5 的 200 点，RMS=0.80、max=2.13，d/dt̂ 单位），远场较干净（3534 点，RMS=0.043；模型远场每 0.001 漂移约 2e-5，真解应≈0）。个别界面点完全光滑（FD 与 AD 一致到 1e-4 相对误差），粗糙程度逐点差异大。归一化正确性已双重验证：纯物理单位（不经 Lc/Tc）重算 FEM FD loss = 2.097382e-4 与归一化路径一致；光滑点上 FD 与 autodiff 吻合。

结论：FD 估计器的步长必须匹配被导对象的光滑尺度——对 FEM 数据越小越好（到求解器步长为止），对网络存在最优步长 h≈0.03–0.1（粗数据时代 adam+FD≈1.08e-5 即接近该最优）。**模型残差的唯一有意义口径是 autodiff。**

### 4.3 残差与解精度仍然负相关

soap 的 autodiff 残差比 adam 低约 16 倍（3.2e-7 vs 5.3e-6），L2 误差反而大近一倍（2.6% vs 1.5%）；界面更平（0.307 vs 0.319 vs FEM 0.335）——"用光滑性换低残差"的结论在精细数据下依然成立。残差 loss 不能单独用于评判模型或对比优化器，必须与 L2 成对报告。

### 4.4 各数字的正确读法

- FEM+FD = 2.1e-4：该网格分辨率下 FD 估计器的地板，非真解物理残差；
- adam/soap + autodiff = 5.3e-6 / 3.2e-7：模型的真实点态 PDE 残差（唯一有意义口径）；
- adam/soap + FD(dt=0.001) = 7.2e-3 / 3.4e-2：数值微分伪影，应弃用；
- L2 = 1.5% / 2.6%：解精度，与残差反向。

## 5. 结论与建议

1. 不要拿任何 FD 读数与 autodiff 训练 loss 直接比较；两者是不同量具，且 FD 的可用步长取决于被导对象。
2. 若论文需要"参考解残差"：FD 在当前 64×64 网格上只能给出 ~2e-4 的地板（空间欠解析主导）；要得到真值需加密空间网格 + Richardson 外推或弱形式残差。
3. adam vs soap 的汇报口径：autodiff loss（5.3e-6 vs 3.2e-7）+ L2（1.5% vs 2.6%）成对给出；soap 残差更低但解更差。
4. 模型的 FD 评估（若必须）应使用 h≈0.03–0.1，并在文中注明步长敏感性。
